# PageScrape Export (working name) — waitlist validation page

A planned browser extension: one click detects list/table data on the page you are viewing and exports a clean CSV or Excel file. Fully local — no cloud, no account, no uploads. Vertical templates for e-commerce product lists, job postings, and property listings. Planned $39 one-time.

- Validation page: https://alapha888.github.io/pagescrape-waitlist/
- Status: product not built. This repo contains only the validation page — no product source code.

- Indicative price (test parameter): $39 one-time. No payment taken, no pre-order.
- Demand evidence: extension category scan round 2, 2026-10-10 — Web Scraper Chrome 500,000+ installs, Instant Data Scraper ~1M users; Data Miner paid tiers from $19.90/month, webscraper.io cloud from ~$50/month; no one-time-purchase product in the $9–39 band between free selector tools and cloud subscriptions (pricing-gap evidence; no sales figures are claimed for this product).
